01The one rule

The room no longer invents.

The master rule is that every guest-facing value traces to live signal or is omitted. But all three TV surfaces booted into their design-preview demo and only switched on the first live message — so a guest could watch a fabricated focus line, a fabricated reveal, and a wall claiming “1,248 minds” that never existed. These embeds are both talking to the same server with no live session running — exactly what a guest would see if the sidecar hiccupped. The before plays fiction; the after holds an honest quiet until real signal arrives.

02One color, one meaning

Orange belongs to the interruption.

The brand reserves orange for a single moment — the engineered interruption. The live surface was spending it all session long: a blinking orange pip in the header and a permanent drifting orange ambient glow. And on the reveal, the ledger’s “Your focus” line was hardcoded orange on every read, though real sessions attach ledgers to reads 02 and 04 too. These are the design-preview modes of both eras — watch the header pip.

04The 100-inch surface

Long readings, long idles, a big panel.

Four smaller TV fixes with outsized effect on a room that runs unattended all day.

tv-live.html

The line no longer piles up at the edge

The x-axis assumed a 7-minute ceiling (t / 420s, clamped). A slow reader’s line stopped advancing and scribbled vertically at the right edge — the exact spot their eyes were parked. The denominator now adapts: span = max(420, last.t), so an over-long session gently compresses instead.

tv-constellation.html

4K-correct idle wall

The wall drew into a fixed 1920×1080 canvas and CSS-scaled it up — every dot softened 2× on a 4K panel while the DOM text beside it stayed pin-sharp. The backing store now sizes to devicePixelRatio physical pixels; all drawing code untouched.

tv-constellation.html

Legible from the armchair

The axis hints that explain what dot placement means were 13px mono at 22% opacity — about 8 arc-minutes of cap height from 4.5m, i.e. smudges. Now 16px at 40%, with the live surface’s honesty caption (“relative to your own session”) bumped too. Hierarchy preserved.

tv-live.html

No ghost of the previous guest

The “fresh session” clear was a no-op — renderLive() early-returned on an empty sample list, leaving the previous guest’s full line on the wall until navigation. An explicit clearPlot() now empties the paths and parks the playhead on idle/welcome.

tv-live.html

The state word keeps its dignity

The 132px display word swapped its text 300ms into a 620ms fade — visibly popping at half-opacity. The swap now waits for the fade-out to complete.

tv-reveal.html

Annotations that don’t collide

On real data the trough guide label could land inside the prose block and a tag label could touch the title. Labels now flip above their guide / below their anchor when they’d cross those zones — verified against the synthetic preview’s four reads.

Also: the fabricated “session low” dashed baseline (a hardcoded v=0.30 that traced to nothing) is gone from served mode, and the wall’s header now reads “In session” instead of “Idle” while a guest’s dot is landing on it.

05Card · profile · email

Takeaways that actually arrive.

The takeaway pipeline carried session data to its render pages in a base64 querystring. Node’s HTTP server rejects headers over 16KB — so any session past about five minutes silently killed the card, the profile and the email at once. And the 210-second plateau fallback makes five-minute sessions normal, not rare.

Payloads ≤12KB keep the legacy querystring; larger ones load the page with ?wait=1 and receive data through window.__setData(...) after load — no size ceiling. Both render pages also now wait on document.fonts.ready before declaring themselves capturable (the PDF could previously print fallback fonts), and the profile PNG embeds the brand woff2s as data-URLs inside the SVG raster — an SVG-as-image can’t reach external webfonts at all, so the old raster always drew system type.

The honesty engine, hardened.

Two structural bugs and six empirical cases. Structural: strict mode keyed off NODE_ENV, which nothing ever set in the packaged app — and a violation threw, taking down all three outputs at once. Strict now derives from packaging itself and redacts loudly instead of throwing, with each output isolated. Empirical, all reproduced then fixed and pinned by a 50-assertion regression test:

Also in this cluster: the Postmark send gets a 10-second abort timeout and persist-before-send — the outgoing report is written to disk before the attempt and deleted only on confirmed success, so a mid-send failure is recoverable instead of gone. Addresses are trimmed and validated server-side; a clearly invalid one skips the provider with a logged reason and still writes the recovery artifact.

06Unattended by design

Built for a day alone.

No operator means every failure is permanent until someone notices. Six of those failure modes are now closed:

app/main.js

A busy port no longer blanks the day

If port 4321 was taken at launch, the app logged one line and carried on — while the TV loaded a URL nothing served. Blank screen until staff intervened. The bind now retries (3s×5, then every 30s forever) and reloads the TV surface the moment it succeeds.

app/main.js

Crash guard with a loop breaker

One unhandled throw killed TV, server and sidecar together. Fatal errors now log to crash.log, attempt cleanup (3s cap), and relaunch — unless more than 3 crashes land inside 10 minutes, which stops a relaunch storm.

app/server.js

Zombie sockets get swept

An iPad that dropped off Wi-Fi never sends a FIN; its socket buffered every broadcast forever (isAlive was write-only). A standard 30s ping/pong heartbeat now terminates the dead.

app/store.js

The wall survives a power cut

The constellation JSON was truncate-written in place — one power cut mid-write and months of dots were gone, permanently, through a silent catch. Writes are now tmp+rename atomic, and a corrupt file is quarantined aside rather than overwritten.

app/orchestrator.js

Only the iPad drives the session

Any laptop on the room network could send guest events — and a duplicated intake message could skip the reading picker entirely. Guest messages are now gated by client role, and only a real reading pick advances out of the picker.

app/orchestrator.js

Reseat coaching that persists

The “reseat the earbud” prompt rode a one-shot broadcast; any state rebroadcast (a resync, a sidecar restart) wiped it while the signal was still bad. It’s now canonical state carried by every broadcast until the signal actually recovers.

07Also this session

The hardware unlock and the home-screen app.

Before the audit, this session solved the real-buds connect. The UUID catalogue turned out to describe buds other than yours — validation rejected the pair (Left device did not match any pair) and a separate probe connection made Windows lose the device address. The connect is now catalogue-free: the SDK’s own validated path is hooked so the pair matcher reads each bud’s real GATT inside the SDK’s tuned connect sequence and picks the EEG service itself — preferring the 2fda vendor family your buds actually expose:

The fit gate also moved to the SDK’s own QC line — it demanded ≤150 kΩ, but dry in-ear electrodes normally sit at 150–500 kΩ with a perfectly clean read, so no real guest could ever pass. It now gates on the SDK’s phase == "good" (≤800 kΩ). This is the change awaiting your hardware run. A liveness check backs it up: streaming with zero EEG frames for 6s raises no_eeg_data instead of a mysteriously flat line.

And the iPad became a real home-screen app: web manifest, standalone meta, portrait lock, and a device mode that drops the desktop-preview bezel and cover-scales the canvas to fill the screen. 08Sequenced, gated

The path from here.

  1. Hardware gate (yours): run npm run dev:real — does the iPad reach “Signal is clear”? One word unblocks everything below.
  2. Dual-bud stability (next, sidecar): re-arm the SDK’s Windows anti-throttle by subscribing the other 2fda services’ TX chars as keepalives; verify the EEG-service pick by actual frame decode; reset the engine per session (guest 2 currently inherits guest 1’s scale and plateau latch); flush stale channel buffers between fit and streaming; rework mid-reading bud-loss recovery end to end.
  3. Unattended hardening: the abandonment watchdog (a walk-away still wedges the room — only a completed close resets it today) and sidecar command acknowledgements.
  4. Ship prep: re-freeze the sidecar (the frozen binary predates every commit), printer test on the HP, POSTMARK_API_KEY, licensed PP Neue Montreal, the real orb art, then the signed Mac Mini build.
  5. Polish backlog: live-line tweening (the 1 Hz steps), the TV type token scale, the strongest-stretch TV treatment (the answer is currently readable off the wall during the guess), a paste step for “your own material”, the battery gate revival.
